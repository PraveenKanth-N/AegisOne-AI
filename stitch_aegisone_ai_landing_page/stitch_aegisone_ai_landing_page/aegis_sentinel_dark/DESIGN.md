## Brand & Style

This design system embodies an authoritative, tactical, and cinematic defense posture. Designed for elite security researchers, enterprise SOC leaders, and adversarial AI engineers, the visual environment balances surgical precision with visceral cinematic depth. It rejects standard corporate SaaS blandness in favor of a high-stakes command center paradigm: deep abyssal blacks, luminous red telemetry, tactical evidence cyan, and stark typographic hierarchy.

### Design Movements & Tone
- **Tactical Cyber Minimalism:** Clean layout architecture punctuated by deliberate razor-thin division lines, high-contrast monochrome structural layers, and focused energetic crimson focal points.
- **Atmospheric Dark Glassmorphism:** Translucent frosted dark panels suspended over subterranean radial gradients and ambient chromatic red illumination, evoking high-end hardware and tactical HUD interfaces.
- **Defensible Editorial Engineering:** Typographic gravitas driven by Space Grotesk's geometric aggression paired with Inter's analytical clarity and JetBrains Mono's unyielding data veracity.

## Colors

The palette establishes an immediate defense posture through stark contrast, controlled crimson luminescence, and precise operational signaling.

### Roles & Semantic Structure
- **Primary (`#F20D32`):** Tactical Crimson. Reserved for critical alerts, active threat mitigation states, primary calls-to-action, active indicators, and high-priority anomalies.
- **Secondary (`#55C7E8`):** Evidence Cyan. Used for analytical telemetry, AI cognitive reasoning threads, verified data artifacts, payload diffs, and intelligence graph vectors.
- **Tertiary (`#8E0924`):** Subdued Sangre. Serves as deep tonal containment borders, active hover states, and background glow base beneath active alerts.
- **Surface Foundations:**
  - `Surface Void` (`#08080B`): Absolute ground plane and canvas canvas tone.
  - `Surface Base` (`#101015`): Card surfaces, telemetry decks, and table containers.
  - `Surface Raised` (`#17171E`): Interactive overlays, floating panels, dropdown manifests, and modal dialogues.
- **Feedback & Status Tokens:**
  - `Verified Success` (`#45D49A`): Integrity verified, exploit neutralized, consensus reached.
  - `Warning Amber` (`#FFB84D`): Latent vulnerability, anomalous behavioral drift, pending auth bypass.

## Typography

The typographic system creates an interplay between display tension and technical rigor.

- **Headings (Space Grotesk):** Engineered geometry with high character identity. Used for high-impact section titles, dashboard telemetry rollouts, and hero statements. Letter spacing remains tightened for structural solidity.
- **Body & Editorial (Inter):** Highly legible, neutral workhorse. Deployed across executive summaries, remediation playbooks, intelligence dossiers, and dense tabular data.
- **Technical & Telemetry (JetBrains Mono):** Reserved for hash signatures, memory offsets, IP tables, exploit chains, and status badges. Emphasizes mathematical precision and unedited system truth.

## Layout & Spacing

Layouts adhere to an engineered 12-column dynamic grid designed for ultra-dense tactical feeds as well as sweeping cinematic overviews.

### Grid & Composition
- **Desktop (1280px+):** 12-column grid with 1.5rem gutters and 3rem outer margins. Content maximum width is capped at 1440px for editorial reading comfort.
- **Tablet (768px – 1279px):** 8-column layout with 1.5rem gutters and 2rem outer canvas margins. Multi-column radar arrays collapse into 2x2 modular matrixes.
- **Mobile (<768px):** 4-column layout with 1rem gutters and 1.25rem margins. HUD readouts and command streams stack vertically in logical order of severity.

### Structural Rhythms
Spacing is strictly anchored to a 4px/8px base metric. Components use tight interior padding (`space-xs` to `space-md`) paired with breathing room (`space-lg` to `space-xl`) between distinct analytical widgets to avoid visual fatigue during continuous SOC operations.

## Elevation & Depth

Visual hierarchy uses volumetric red backlighting, matte dark layers, and hairline luminosity borders rather than traditional drop shadows.

### Atmospheric Volumetrics
- **Sub-Surface Ambient Glow:** High-impact nodes or critical attack surface cards project an atmospheric, soft-red radial backglow (`radial-gradient(circle, rgba(242,13,50,0.18) 0%, transparent 70%)`).
- **Glassmorphic Hud Plates:** Background panels use 16px to 24px backdrop blur over `rgba(16, 16, 21, 0.75)` with a hairline 1px border of `rgba(255, 255, 255, 0.08)`.
- **Active Edge Highlight:** Hover and active focus states trigger a crimson gradient border transition (`linear-gradient(135deg, #F20D32 0%, rgba(142, 9, 36, 0.3) 100%)`) accompanied by an outer edge luminescence (`0 0 20px rgba(242, 13, 50, 0.25)`).

## Shapes

The interface embraces a precise, military-hardware industrial geometry.

### Radius Metrics
- **Base (0.25rem / 4px):** Applied to buttons, status tags, form fields, code snippets, and telemetry chips.
- **Large (0.5rem / 8px):** Applied to telemetry cards, floating glass HUD dialogs, data tables, and radar widgets.
- **Extra-Large (0.75rem / 12px):** Applied exclusively to top-level view containers, modal panels, and screen boundary viewports.

Sharp transitions and precise corners reflect engineering discipline and defense readiness, actively avoiding playful pill radii.

## Components

### Buttons & Action Triggers
- **Primary Tactical:** Solid `#F20D32` background with white bold Space Grotesk text, 4px corner radius, and subtle outer crimson flare on hover (`box-shadow: 0 0 16px rgba(242, 13, 50, 0.45)`).
- **Secondary Ghost:** Hairline border (`rgba(255, 255, 255, 0.15)`), transparent surface, Inter medium label. On hover: border tints to `#55C7E8` with matching soft cyan ambient glow.
- **Destructive/Quarantine:** `#8E0924` surface with `#F20D32` 1px border and Space Grotesk uppercase typography.

### Data Chips & Telemetry Tags
- Rendered in JetBrains Mono (`label-badge`) with uppercase tracking.
- Composed of an ultra-dark background (`#101015`), a 1px matching status outline, and an active blinking indicator dot (e.g., `#F20D32` for `THREAT_ACTIVE`, `#45D49A` for `MODEL_VERIFIED`).

### Threat Cards & Surface Panels
- Constructed from `Surface Base` (`#101015`) with a 1px border (`rgba(255, 255, 255, 0.06)`).
- Features an optional tactical corner accent or subtle grid-line watermark in the header block to delineate pipeline boundaries.

### Input Fields & Search Bars
- Background set to `Surface Void` (`#08080B`) with an inset depth aesthetic.
- Monospaced typography for search, query, and IP string inputs. Focus state transitions the border to solid `#F20D32` with an immediate zero-latency glow.

### Specialized Radar & Diff Components
- **Neural Threat Radar:** Concentric target circles traced in 1px cyan/crimson wireframes (`rgba(85, 199, 232, 0.15)`) with a rotating radial sweep gradient highlighting intercepted vectors.
- **Payload Diff Blocks:** Side-by-side terminal windows displaying red-tinted strike zones (`rgba(242, 13, 50, 0.12)`) alongside cyan-tinted verified neural mitigations (`rgba(85, 199, 232, 0.12)`).
